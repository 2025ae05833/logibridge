## The two vibration rates

Task A1 specifies 500 Hz × 3 axes; Task C1 specifies a 0.5 Hz `vibration_rms`
stream. These are different points in one chain: the raw accelerometer, and the
RMS computed from it on the sensor node. The bandwidth case uses the raw rate
because that is what a cloud architecture would have to ship. Computing RMS at
the sensor is itself a 3,000× reduction before anything reaches the broker.
